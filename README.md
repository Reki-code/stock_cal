# Stock Trading Analyzer Tool

This tool is designed specifically for Chinese tax residents.

## Features
- Easy tracking of stock trades
- Calculation of capital gains and losses
- Generation of tax reports compliant with Chinese regulations

## Usage
1. Import your trade data.
2. Use the calculator for capital gains.
3. Generate the report for tax submission.

## Installation
Clone this repository and install the necessary dependencies to get started with the tool.
